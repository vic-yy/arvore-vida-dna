O ALGORITMO

Needleman-Wunsch

Uma tabela em que cada casa guarda a melhor pontuação possível até ali. Voltando pelo caminho laranja, o alinhamento aparece.

+1

letra igual

−1

letra diferente

−2

buraco

Programado do zero em Python (preenchimento da matriz + traceback)

Como o computador acha o melhor alinhamento entre bilhões de possibilidades? Com o algoritmo de Needleman-Wunsch, que eu programei do zero. Ele monta uma tabela: cada casinha guarda a melhor pontuação possível até aquele ponto. Letra igual dá ponto, letra diferente ou buraco tira ponto. Depois é só seguir o caminho de volta, a linha laranja, e o alinhamento aparece. Aqui o exemplo é curto (GATTACA contra GCATGCA); o notebook faz o mesmo com os genes de 1.140 letras.
